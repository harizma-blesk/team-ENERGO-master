# Camera Monitor - Python Version (В разработке)

Переведенная с C++/Qt на Python версия системы мониторинга кабинетов с использованием компьютерного зрения (YOLO).

**Текущий статус**: 🎨 Фаза 5 - GUI интерфейс (завершена)

**Завершено**:

## 🚀 Быстрый старт

```bash
# Клонировать репо
git clone <repo_url>
cd CameraMonitor_Python

# Создать virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
# или source venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt

#Установить модели YOLO
pip install huggingface_hub
python -c "from huggingface_hub import hf_hub_download; hf_hub_download(repo_id='Ultralytics/assets', filename='yolov8n.pt', local_dir='models')"

# Запустить приложение
python run.py
```

### 🎯 Что увидите после запуска:
1. **Главное окно** с вкладками: Камера, Поиск кабинетов, Настройки
2. **Вкладка Камера**: Управление видео и просмотр детекции в реальном времени
3. **Вкладка Поиск**: Форма для запроса информации о кабинетах
4. **Вкладка Настройки**: Конфигурация всех параметров приложения

### Фаза 1: Подготовка окружения
- **Config**: Система конфигурации с валидацией и дефолтными значениями
- **Database**: SQLAlchemy 2.0 ORM с SQLite, поддержка миграций
- **Logger**: Структурированное логирование с ротацией файлов

### Фаза 3: Обработка видео и CV
- **CameraManager**: Захват видео с RTSP/локальных камер, многопоточная обработка
- **PersonDetector**: YOLOv8/v11 детекция людей с поддержкой COCO классов
- **ImageConverter**: Конвертация между OpenCV, PyQt6, PIL форматами
- **DetectionVisualizer**: Визуализация детекций с bounding boxes и метками
- **ModelDownloader**: Автоматическое скачивание YOLO моделей

### Фаза 5: GUI интерфейс
- **MainWindow**: Главное окно с вкладками, меню и строкой состояния
- **CameraWindow**: Live видео с детекцией, управлением камерой и статистикой
- **RequestWindow**: Поиск свободных кабинетов с формой запросов и результатами
- **SettingsWindow**: Настройки приложения с вкладками для разных категорий
- **DetectionOverlay**: Наложение bounding boxes на видео в реальном времени
- **StatusUpdateThread**: Фоновый мониторинг статуса компонентов
