# 📊 Резюме проекта CameraMonitor_Python

## Обзор

**Проект**: Миграция системы мониторинга кабинетов с C++/Qt на Python

**Статус**: 📝 Фаза планирования (100% готов) - разработка НЕ начата

**Тип**: GUI приложение для мониторинга видео + ML детекция

## Технический стек

| Компонент | C++ (текущее) | Python (целевое) |
|-----------|---|---|
| GUI | QML + Qt Quick | PyQt6 |
| Видео | OpenCV | OpenCV |
| ML | ONNX Runtime | ultralytics YOLO |
| БД | SQL Server | SQLite |
| Сеть | Qt Networking | Python sockets |
| Конфиг | Qt Settings | configparser |

## Ключевые компоненты для разработки

### src/core/ (бизнес-логика)
- `config.py` - парсинг settings.ini
- `database.py` - SQLAlchemy ORM
- `camera.py` - OpenCV захват видео
- `detector.py` - ultralytics YOLO
- `network.py` - UDP/TCP сокеты

### src/gui/ (пользовательский интерфейс)
- `main_window.py` - главное окно (tabs)
- `camera_window.py` - live видео + детекция
- `request_window.py` - поиск кабинетов
- `widgets.py` - общие компоненты

### src/utils/ (утилиты)
- `logger.py` - система логирования
- `image_utils.py` - конверсия изображений
- `validators.py` - валидация данных

### Корневые файлы
- `src/main.py` - точка входа приложения
- `run.py` - скрипт запуска
